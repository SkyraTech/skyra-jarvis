# Skyra Agent Runtime

Repository update (2026-10-14): this component now belongs to `skyra-jarvis` at `skyra-jarvis/packages/agent-runtime`. Do not create a separate GitHub repository for `skyra-agent-runtime`. Specifications were preserved; implementation is still pending.

# Jarvis Windows Desktop

Repository update (2026-10-14): this component now belongs to `skyra-jarvis` at `skyra-jarvis/apps/desktop`. Do not create a separate GitHub repository for `skyra-jarvis-desktop`. Specifications were preserved; implementation is still pending.

The dedicated Windows control centre for Jarvis: a workflow canvas of available subsystems, live task graphs, conversation panels, approvals, memory and incidents. Uses its own UI design, not Skyra Platform components.

## Current status

New documentation-only project. No application shell, installer or UI implementation exists here yet.

This documentation describes the target. It does not claim implementation, deployment or passing runtime tests. No source code was changed in the documentation reset.
